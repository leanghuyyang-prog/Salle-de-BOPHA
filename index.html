✏️ 2. Grammaire

Le verbe ÊTRE

Je suis

Tu es

Il / Elle est

Nous sommes

Vous êtes

Ils / Elles sont

Exemple : Je suis professeur.

Le verbe AVOIR

J'ai

Tu as

Il / Elle a

Nous avons

Vous avez

Ils / Elles ont

Exemple : J'ai un livre.

Les articles

Masculin : le / un

Féminin : la / une

Pluriel : les / des

Exemple : Une maison.

La négation

Ne ... pas

Je parle français.

Je ne parle pas français.
